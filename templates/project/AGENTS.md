# Projeto consumidor do RedeTI Dev Agent Framework

Carregar a politica central no checkout do framework (`~/.hermes/redeti-framework/AGENTS.md`) e complementar com as decisoes especificas deste projeto.

- ChatGPT cria, revisa e publica codigo, scripts, testes e conteudo.
- Hermes sincroniza a branch indicada, instala, executa testes, diagnostica e documenta resultados. Nao desenvolve patches.
- `/redeti-next` usa o repositorio GitHub atual e busca Issues `[HERMES NEXT]` com label `hermes-ready`.
- Manter segredos fora do Git. Proteger producao e dados reais.
- Mudancas permanentes em cognicao, tools, skills, contexto e rotinas requerem aprovacao.
- Nao declarar sucesso sem evidencias e SHA remoto.
